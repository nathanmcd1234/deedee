All product buttons point to Diedrian's Payhip pages.
Images are pulled from the existing Payhip CDN image URLs so the site already has product and portrait photography.

To publish on GitHub Pages:
1. Upload all files to the repository root.
2. Keep the filenames exactly as shown.
3. Enable GitHub Pages for the repository.
4. Open the published index.html URL.

To move to Wix/Webflow later:
Use the pages and copy as the content/design blueprint. The site is intentionally organized into separate pages so each section can be recreated as editable content blocks.
